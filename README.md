## Learning Path

A practical progression through this collection is:

1. Start with **Port Sleuth: Nmap Service Hunt** and **Momentum Scanner** to build reconnaissance skills.
2. Continue with **Momentum Cipher Trail** for cryptographic problem solving.
3. Explore **Momentum Lab: Cipher to Redis** to connect cipher analysis with Redis concepts.
4. Practice credential and traffic investigation using the dedicated Fawkes and Spellbound challenges.
5. Progress through the Fawkes enumeration and root-oriented labs.
6. Finish by reviewing the security lessons from each challenge and documenting possible defensive controls.

## How to Use the Labs

1. Select a challenge from the index.
2. Read the provided lab instructions carefully.
3. Identify the primary technology or security concept involved.
4. Work exclusively within the authorized CTF environment.
5. Record observations, commands, errors, and findings.
6. Explain the security principle behind each successful discovery.
7. Consider how the issue could be detected or mitigated in a real environment.

Only perform security testing where you have explicit authorization.
